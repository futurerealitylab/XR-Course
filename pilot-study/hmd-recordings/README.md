# MetaMuseum Pilot Study HMD Recordings

Raw HMD screen recordings from the MetaMuseum pilot study are stored in Google Drive instead of GitHub, because the video folder is approximately 2.5 GB and several files exceed GitHub's normal 100 MB per-file limit.

Google Drive folder:
https://drive.google.com/drive/folders/1_yk6A8yZ5QcCVZ-Mrx-XccD7qCm3Xs-j?usp=sharing

Contents:
- `manifest.csv` lists the local recording filenames, recording timestamps parsed from filenames, file sizes, and original local source paths.
- Source device/app naming follows the Oculus browser recording convention: `com.oculus.browser-YYYYMMDD-HHMMSS-0.mp4`.

Notes:
- The videos were recorded during study runs using the HMD recording button.
- Raw videos are intentionally not committed to this repository to keep the code repository lightweight and avoid Git LFS quota/bandwidth issues.
- If the Drive folder is moved or permissions change, update this README with the new share link.
